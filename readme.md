## 📄 File Explanations

| File | Purpose |
|------|---------|
| `src/index.js` | Main automation logic — scraping, processing, saving data |
| `src/scheduler.js` | Sets up cron job to run automation on a schedule |
| `src/notify.js` | Sends email notification with run summary when automation finishes |
| `src/utils/logger.js` | Appends a log line to logs/ on every run |
| `src/utils/helpers.js` | Shared functions reused across multiple files |
| `config/config.js` | All constants and settings in one place — easy to change |
| `data/results.json` | Output file where automation saves its results |
| `logs/app.log` | Record of every run — timestamp, items, errors, time taken |
| `.env` | Stores Gmail credentials and other secrets securely |
| `.gitignore` | Prevents node_modules, .env, data, logs from being pushed |

## 🔐 Setup Environment Variables

Create a `.env` file in the root folder:

```
GMAIL_USER=youremail@gmail.com
GMAIL_PASS=your_app_password_here
```

> To get a Gmail App Password: myaccount.google.com → Security → 2-Step Verification → App Passwords

---

## ▶️ How to Run

**Run once manually:**
```bash
node src/index.js
```

**Run on schedule (cron):**
```bash
node src/scheduler.js
```

**Keep running in background with pm2:**
```bash
pm2 start src/scheduler.js
```

## 📅 Schedule

This automation runs on the following cron schedule:

